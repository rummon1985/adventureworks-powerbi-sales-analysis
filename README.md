# AdventureWorks Power BI Sales Analytics

## Project Overview
An interactive Power BI dashboard designed to analyze AdventureWorks sales performance, profitability, product returns, regional trends, and customer purchasing behavior.

The report consists of four pages: Executive Summary, Territory Analysis, Product Analysis, and Customer Analysis.

## Key Performance Indicators

| KPI | Value |
|---|---:|
| Total Revenue | $24.91M |
| Total Profit | $10.46M |
| Net Sales | $24.15M |
| Profit Margin | 42.0% |
| Total Orders | 25K |
| Quantity Sold | 84K |
| Return Rate | 2.17% |

## Dashboard Analysis

### 1. Executive Summary
Provides an overview of overall business performance using sales, profit, order, and return KPIs.

**Key observations:**
- Accessories lead order volume with 16,983 orders.
- Bikes follow with 13,929 orders.
- Tires and Tubes is identified as the most-sold subcategory.
- Bib-Shorts is identified as the most-returned subcategory.

### 2. Territory Analysis
Compares geographical performance using maps, regional breakdowns, and profitability metrics.

**Key observations:**
- North America generates approximately $9.43M in net sales.
- Europe contributes approximately $7.54M.
- The Pacific region contributes approximately $7.18M.
- Overall profit margin is 42%.

### 3. Product Analysis
Uses a decomposition tree to explore returned quantities across product categories, subcategories, and individual products.

**Key observations:**
- Accessories account for 1,130 returned units.
- Bikes account for 429 returned units.
- Clothing accounts for 269 returned units.
- Regional net sales are illustrated using a donut chart.

### 4. Customer Analysis
Uses RFM segmentation to evaluate purchasing behavior and identify retention opportunities.

**Key observations:**
- About to Sleep: 26.58%
- Lost Customers: 16.01%
- Promising: 11.95%
- New Customers: 11.83%
- Champions: 10.17%

The page also tracks monthly customer activity, purchase frequency, customer-level revenue, average order value, and recency.

## Tools and Techniques

- Microsoft Power BI
- DAX measures
- RFM customer segmentation
- KPI reporting
- Interactive filtering
- Data visualization
- Sales and profitability analysis

## Business Recommendations

1. Develop re-engagement campaigns for customers in the About to Sleep and Lost segments.
2. Investigate product categories with high return volumes.
3. Monitor geographical profitability when allocating sales resources.
4. Track monthly sales and customer retention to identify sustainable growth opportunities.

## Conclusion

The AdventureWorks Power BI dashboard provides a consolidated view of business performance across sales, products, customers, and territories. It demonstrates how interactive analytics can support evidence-based business decisions.
